# Smart Serve: Week 1 Plan (for instructor checkpoint)

**Course:** IT211 – Section 2-3  
**Prepared by:** Mark Padua, Project Manager

## 1. Project summary
Smart Serve is a Java application for fast-food and restaurant customers. It removes the need to line up: customers order from a digital menu, track their order live, and reserve or check available tables.

## 3. Requirements (draft, to be checked against the handout)
**Must**
- View the menu by category
- Place an order
- Track order status: Received → Preparing → Ready → Completed
- See which tables are available
- Reserve a table

**Should**
- Customize an item (size, add-ons)
- Staff screen to update order status
- Cancel a reservation

**Real-world limit the system enforces:** a table cannot be reserved by two customers for the same time slot.

## 4. Planned classes and owners
See `class-assignments.md`. Twelve classes, two per member: `Customer`, `OrderStatus`, `MenuCategory`, `MenuItem`, `Order`, `OrderItem`, `OrderManager`, `TableManager`, `Cart`, `ConsoleMenu`, `Table`, `Reservation`.
